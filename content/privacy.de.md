## Kurzfassung

Dies ist eine statische Website. Sie setzt **keine Cookies**, nutzt **keine
Analyse-Tools** und bindet **keine Skripte oder Tracker Dritter** ein.
Schriften werden von dieser Domain ausgeliefert, nicht von einem
Font-CDN eines Drittanbieters.

## Hosting

Die Seite wird über **GitHub Pages** (GitHub, Inc.) ausgeliefert. Beim Aufruf
überträgt Ihr Browser technisch notwendige Daten an die Server von GitHub —
darunter Ihre IP-Adresse, die aufgerufene URL, den Zeitpunkt der Anfrage und
den User-Agent Ihres Browsers. GitHub verarbeitet diese Daten, um die Seite
auszuliefern und Missbrauch abzuwehren. Einzelheiten dazu finden sich in den
Datenschutzhinweisen von GitHub.

## Kontakt per E-Mail

Wenn Sie mir schreiben, werden Ihre Nachricht und Ihre Adresse ausschließlich
zur Beantwortung Ihrer Anfrage verwendet.

## Ihre Rechte

Nach der DSGVO haben Sie das Recht auf Auskunft, Berichtigung, Löschung,
Einschränkung der Verarbeitung, Datenübertragbarkeit und Widerspruch. Wenden
Sie sich dafür an die im [Impressum](/de/impressum/) genannte Adresse.
